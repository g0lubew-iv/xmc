# xmc

`xmc` это расширение для Python на C, реализующее
быстрый PRNG (xoshiro256) и базовые методы Монте-Карло.

## Функционал

- `xmc.RNG`: тип-расширение на C, реализующий xoshiro256.
- `xmc.estimate_pi(n, seed=0)`: оценка числа π методом Монте-Карло.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
```

- Python 3.11+
- GCC (или clang), поддержка C11

## Использование

```python
import xmc

r = xmc.RNG(seed=42)
print(r.random())
print(r.randint(1, 6))
print(repr(r))

print(xmc.estimate_pi(10_000_000))
```

## 1. PRNG (xoshiro256**)

PRNG (pseudo-random number generator) это детерминированный алгоритм генерации последовательности чисел, выглядящей случайной. Для одного и того же состояния (seed), получаем одну и ту же последовательность.

	- Внутри PRNG содержится состояние **state**, которое для каждого вызова:
		(a) вычисляет псевдо-рандомное число,
		(b) мутирует себя так, чтобы следующее число было (статистически) независимым;

	- Реализация в соответствии с алгоритмом **xoshiro256\*\*** (Blackman & Vigna, 2018):
		(a) из себя он представляет комбинацию XOR, сдвигов и умножений,
		(b) компактный state длиной `32` байта,
		(c) период: `2^256 - 1`,
		(d) не крипто-устойчив (для генерации паролей не годится).

## 2. Monte-Carlo methods

**Монте-Карло** это семейство методов, которые оценивают числовые
величины (интегралы, матожидания, вероятности) через случайное
сэмплирование.
В основе лежит закон больших чисел (ЗБЧ) и центральная
предельная теорема (ЦПТ).

### 2.1. Постановка задачи

Пусть есть случайная величина `X` с неизвестным матожиданием
`μ = E[X]`, и мы умеем генерировать независимые значения
`X[1], X[2], ..., X[n]` с тем же распределением, что у `X`.

Оценка Монте-Карло это **выборочное среднее**:

```
μ̂[n] = (X[1] + X[2] + ... + X[n]) / n
```

### 2.2. Почему оценка сходится (ЗБЧ)

**Усиленный закон больших чисел** (Колмогоров): если `X[1], X[2], ...`
независимы, одинаково распределены и `E[|X|] < inf`, то

```
μ̂[n] -> μ̂	почти наверное при n -> inf
```

### 2.3. Как быстро сходится и с какой ошибкой (ЦПТ)

**Центральная предельная теорема** (Линдеберг–Леви): если `X[1], X[2], ...`
независимы, одинаково распределены, `E[X] = μ` и `Var(X) = σ² < inf`, то

```
sqrt(n) * (μ̂[n] - μ) / σ  ->  N(0, 1)	по распределению при n -> inf
```

На практике это значит, что для больших `n`:

```
μ̂[n] ≈ μ + (σ / sqrt(n)) * Z,	где Z ~ N(0, 1)
```

Отсюда:

- **Скорость сходимости: `1 / sqrt(n)`**, это фундаментальное ограничение метода.
- **Стандартная ошибка:** `SE(μ̂[n]) ≈ σ / sqrt(n)`.
- **Доверительный интервал 95%:** `μ̂[n] +/- 1.96 * σ / sqrt(n)`.
